# BALANCEO-CARGAS-NGINX-SERVER
Proyecto final del curso "Sistemas Operativos": Este proyecto incluye la configuración de una infraestructura contenerizada con un servidor Nginx como proxy inverso, múltiples instancias de backend, y la integración de un sistema de monitoreo como Prometheus y Grafana, junto con sus exportadores (Nginx Prometheus Exporter y cAdvisor).
